Improve the UI of our customer-facing subscription portal (Next.js/React).
Occasionally build or improve the UI of the internal tools our team uses every day.

Expert-level HTML, CSS, JavaScript/TypeScript, and React. You can turn a Figma file into a pixel-perfect, responsive page quickly.

Experience building on Shopify (themes, Liquid, sections) and/or building HTML email.
Fast without being sloppy. You ship quickly and what you ship works on every screen.
AI-native, with real fundamentals. You use AI tools to move faster and you understand everything you ship.
